YOUR MEMORIES. YOUR CHOICE.

A little light. With open AI.

The open-weight model runs on your CPU and selects passages from your archive. No API key is needed.

Checking the model...

One download. No key.

Install the dependencies and download the verified model files once. Readings then work offline.

npm ci
npm run setup:model
npm start

About 86 MB of model files. The English model selects source text; it does not write new memories or speak as a person.

This choice lasts only for this tab. You can turn it off here. Provider retention policies apply; use the fictional sample when trying the service.

Optional hosted AI configuration

Copy .env.example to .env, set the following values in that file, and restart the app. See the README for a supported open-weight model.

AI_BASE_URL=your-provider-HTTPS-endpoint
AI_MODEL=your-open-weight-model
AI_API_KEY=your-provider-key

API keys stay on the server. Never put a key into a fragment or an exported collection. Connection checks contact the provider without sending archive text.

What stays here

The app has no analytics or external fonts. Custom archives stay in this tab unless you choose browser storage, export a file, or request a hosted reading. Browser storage and exported files are not encrypted.
